# Rhythm

- [Web version](WEB-version/README.md): Rhythm in your browser, with the same violet/blue branding, music library, queue, audio settings, downloads, and listening Replay. The backend runs entirely in Python; no Node.js server or Flutter installation is required.
- [app version](app%20version/README.md): Rhythm standalone Flutter/Dart app for Android, iOS, and macOS. Search and streaming connect directly to YouTube; playlists, listening history, and downloads stay on the device. No backend server is required by the app.
