# Rhythm branding assets

- `rhythm-original.png`: unchanged image supplied by the user, used in About and launch screens.
- `rhythm-icon.png`: compact symbol asset produced with the built-in image-generation tool, used in navigation, artwork placeholders and launcher icons.
- Platform PNG sizes are exported from these sources with macOS sips; no Python runtime is needed by the app.

Prompt used with the original image as edit target:

> Produce a square app icon asset, preserving the supplied glossy folded musical-note R symbol faithfully: exactly same silhouette, internal ribbon shapes, neon violet/magenta/blue highlights and cyan right tip. Remove only the RHYTHM wordmark and extra outer margins. Center the unchanged symbol on the same near-black background, with safe margins around every tip (symbol occupies about 70% of square width and height). No new shapes, no rounded container, no words, no redesign, no watermark. Intended for native launcher icons.
